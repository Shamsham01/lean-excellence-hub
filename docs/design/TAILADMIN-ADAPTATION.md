# TailAdmin visual adaptation (MIT)

LEH’s platform shell, tokens, and several UI primitives follow layout and styling patterns from [TailAdmin free Next.js admin dashboard](https://github.com/TailAdmin/free-nextjs-admin-dashboard) (MIT).

- Licence and attribution: [`third-party/TAILADMIN-MIT.txt`](../../third-party/TAILADMIN-MIT.txt)
- LEH palette and product rules: [`tailadmin-design-system.md`](./tailadmin-design-system.md)
- High-fidelity HTML mockups (1440×900, mobile PPS): generated under `/opt/cursor/artifacts/mockups/` via `build-all-mockups.mjs`

Adapted areas include menu item utilities (`leh-menu-item*`), theme shadows, card/input/button density, platform topbar search group, and problem-solving workspace chrome.
